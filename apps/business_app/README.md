# business_app (owner + staff)

Platform folders (`android/`, `ios/`) are generated by Flutter on your machine, not stored in this zip:

```powershell
cd apps\business_app
flutter create --platforms=android,ios --project-name salon_business --org com.yourorg .
flutter pub get
flutter run --dart-define=API_BASE_URL=http://10.0.2.2:3000/api/v1
```

`flutter create .` keeps the existing `lib/`, `pubspec.yaml` and `analysis_options.yaml`.
If it overwrites `pubspec.yaml`, copy the version from this zip back in, then run `flutter pub get`.
